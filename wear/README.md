# ישראל TV+ לשעון (Wear OS)

אפליקציה נייטיב לשעונים חכמים עם Wear OS 3 ומעלה (Kotlin + Compose for Wear OS Material 3 + Media3).

## מה יש בה
- **מסך בית עגול:** "מתנגן עכשיו", המשך צפייה (2 אחרונים), מדפים: ערוצי ישראל, רדיו ישראלי, ספורט, ילדים, סרטים וסדרות, מועדפים, כל הקטגוריות.
- **רשימות ערוצים** עם לוגו, מספר ומדינה/קטגוריה. לחיצה ארוכה = הוספה/הסרה ממועדפים.
- **נגן:** וידאו מלא במסך העגול (כפתור ⛶ בין "התאמה" ל"מילוי"), פני רדיו עם לוגו, ⏮ ⏯ ⏭ להחלפת ערוץ ברשימה, ‏－/＋ ועוד **הכתר** לעוצמת השמע של השעון. בווידאו הפקדים נעלמים אחרי 4 שניות, נגיעה מחזירה.
- **ממשיך לנגן ברקע** (רדיו עם מסך כבוי) דרך Media3 MediaSession – מופיע גם בפקדי המדיה של השעון (לחיצה עליהם פותחת את הנגן). ניתוק אוזניות = השהיה.
- **אין השתקה:** ערוץ תמיד מתנגן ב-`volume = 1`; רק עוצמת המדיה של השעון משתנה.
- רשימת הערוצים: העותק שבתוך ה-APK (עובד מיד ובלי רשת), ואז הרשימה המעודכנת מהאתר – ערוצים חדשים מגיעים בלי עדכון אפליקציה. קשת 12/24 מקבלות כרטיס צפייה מ-mako כמו בשאר האפליקציות.
- עברית מימין לשמאל בכל שעון, בלי קשר לשפת המכשיר.

## בנייה
```
cd wear
gradlew assembleRelease
```
הקובץ: `wear/app/build/outputs/apk/release/app-release.apk` (חתום במפתח של אפליקציית האנדרואיד אם הוא קיים ב-`~/.android`).
אפליקציה נפרדת: שם החבילה `com.israeltv.plus.wear`. מתקינים אותה מאפליקציית הטלפון (הגדרות ← התקנה בשעון) או עם adb; ה-versionCode בטווח נפרד (1,000,000+) והגרסה נקראת מ-`VERSION` בלי לשנות אותו.

## התקנה על שעון
בשעון: הגדרות ← מערכת ← אודות ← לחיצה 7 פעמים על "מספר Build", ואז אפשרויות למפתחים ← ניפוי באגים באלחוט.
```
adb pair <כתובת:פורט>
adb connect <כתובת:פורט>
adb install app-release.apk
```
