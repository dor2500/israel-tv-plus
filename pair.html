חיבור מפתח הדיבוב לטלוויזיה

הדיבוב לעברית בטלוויזיה עובד עם Google Gemini – מפתח חינמי. מדביקים אותו כאן, והוא נשלח מוצפן ישירות לאפליקציה שעל המסך.

  1. פותחים את aistudio.google.com/apikey ונכנסים עם חשבון Google
  2. לוחצים Create API key ומעתיקים את המפתח (מתחיל ב-AIza)
  3. מדביקים כאן ולוחצים "שליחה לטלוויזיה"

המפתח מוצפן בטלפון (AES-GCM) עם קוד שנמצא רק בקוד ה-QR שעל הטלוויזיה, ועובר דרך שירות ההודעות ntfy.sh בלי שאפשר לקרוא אותו. הוא נשמר רק בטלוויזיה.
