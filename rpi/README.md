# Israel TV+ Dedicated Appliance OS for Raspberry Pi (Pi 2, 3, 4, 5)

הוראות התקנה והפעלה של מערכת ההפעלה הייעודית **Israel TV+ OS** על רספברי פאי (Raspberry Pi 2 ומעלה).

---

### מה המערכת מספקת?
- 📺 **סטרימר טלוויזיה ייעודי (Appliance / Set-Top Box)**: המכשיר מופעל ישירות לתוך Israel TV+ במסך מלא (Kiosk Mode) ללא דסקטופ כבד או חלונות מיותרים.
- 🎮 **שליטה ישירה משלט הטלוויזיה (HDMI-CEC)**: חיצי השלט, כפתור OK, כפתור חזור, מקשי הנגינה וכפתורי הצבעים שולטים ישירות באפליקציה דרך חיבור ה-HDMI – ללא צורך בעכבר או מקלדת!
- ⚡ **האצת חומרה מלאה (GPU Hardware Acceleration)**: תמיכה מובנית ב-VideoCore IV / VI / VII לצפייה חלקה ב-60 FPS בשידורי ספורט, קולנוע וחדשות.
- 🚀 **תאימות מלאה**: תומך ב-Raspberry Pi 2B, 3B, 3B+, 4B, 400, 5, ו-Raspberry Pi Zero 2W.

---

### שיטת התקנה 1: התקנה מהירה בלחיצה אחת (מומלץ)
אם כבר יש לכם כרטיס זיכרון עם Raspberry Pi OS Lite מותקן:
1. התחברו ל-Terminal ברספברי פאי והריצו:
```bash
curl -sSL https://raw.githubusercontent.com/dor2500/israel-tv-plus/master/rpi/install.sh | sudo bash
```
2. בסיום ההתקנה, הפעילו מחדש:
```bash
sudo reboot
```
וזהו! הרספברי פאי יעלה אוטומטית כסטרימר Israel TV+ מלא.

---

### שיטת התקנה 2: צריבת קובץ Image ישירות לכרטיס SD
1. הורידו את קובץ ה-Image: `IsraelTVPlus-RaspberryPi.img.xz`
2. פתחו את תוכנת **Raspberry Pi Imager** או **BalenaEtcher**.
3. בחרו את קובץ ה-Image ואת כרטיס ה-SD (מומלץ 16GB או יותר במהירות Class 10 / A1).
4. לחצו על **Write / Flash**.
5. הכניסו את הכרטיס לרספברי פאי, חברו כבל HDMI לטלוויזיה וחברו חשמל.

---

### מיפוי מקשי שלט הטלוויזיה (HDMI-CEC)
| כפתור בשלט הטלוויזיה | פעולה ב-Israel TV+ |
|---|---|
| **חצים (מעלה / מטה / ימינה / שמאלה)** | ניווט בממשק הטלוויזיה, בין ערוצים ומדריך שידורים |
| **Select / OK / Enter** | פתיחת ערוץ / אישור בחירה |
| **Back / Exit / Return** | חזרה לתפריט / סגירת נגן / יציאה מהגדרות |
| **Play / Pause / רווח** | השהייה והמשך ניגון |
| **כפתור אדום (Red)** | מעבר ישיר למועדפים |
| **כפתור ירוק (Green)** | מעבר למדריך שידורים (EPG) |
| **כפתור צהוב (Yellow)** | מעבר לסדרות VOD |
| **כפתור כחול (Blue)** | שינוי יחס תמונה (16:9 / זום) |
| **ספרות 0-9** | מעבר ישיר למספר ערוץ |
